# Google Code-in 2019: Drupal tasks

Tasks I completed for the **Drupal** organisation during [Google Code-in 2019](https://codein.withgoogle.com/archive/) (2 Dec 2019 – 23 Jan 2020), Google's open-source contest for pre-university students. I completed 13 tasks in total that year; these four involved writing Drupal 8 modules in PHP.

| Folder | Task |
|---|---|
| `GCI-task-form` | A custom Drupal 8 module with a route and a form built on the Form API (`GciForm.php`). |
| `porting-a-d7-module-to-d8` | Ported the *Lyric Sheet Chords* text filter from Drupal 7 to Drupal 8 as a filter plugin. |
| `Name-Filter` | A text-format filter plugin that replaces a user's first name with their last name. |
| `Js-Module-Block-Calculator` | A block plugin that renders a simple JavaScript calculator, attached through a Drupal library. |

Each folder was originally its own repository. They were merged here with their full commit history preserved.

**Tech:** PHP, Drupal 8 (plugins, routing, Form API, libraries), JavaScript
